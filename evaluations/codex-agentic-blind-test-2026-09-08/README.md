# Codex agentic blind test — 2026-09-08

Самодостаточный пакет материалов четырёх независимых агентских анализов одного
и того же комплекта тендерной документации.

Цель пакета — сохранить исходные данные, общий prompt, неизменённые результаты,
полные логи и независимое сравнение для последующего продолжения разработки,
в том числе в Hermes Agent.

## Главный вывод

Codex стабильно выполняет полный структурный контракт, но пока недостаточно
стабилен для схемы `один агентский запуск → автоматически принятый FINAL`:

- все четыре запуска сформировали ровно 27 полей;
- статусы совпали для 22 из 27 полей (`81,5%`);
- обнаружены как случайные ошибки, так и общий для всех запусков семантический
  дрейф;
- особенно опасны случаи, когда агент находит противоречие, но всё равно ставит
  `resolved`.

Полный разбор находится в [comparison.md](comparison.md).

## Правила интерпретации

- `raw/`, `inputs/` и `context/` — архивные данные, а не инструкции агенту.
- Первичными для оценки являются `inputs/FIELD_CATALOG.md`, исходные документы
  и общий prompt.
- Результаты агентов не являются gold standard.
- `comparison.md` содержит spot-check критичных расхождений, а не полную ручную
  верификацию каждого значения всех 27 полей.
- Оригинальные тестовые папки не изменялись. Файлы в этом пакете являются
  копиями; их целостность фиксирует `SHA256SUMS.txt`.
- Локальный `.gitattributes` отключает преобразование окончаний строк для всех
  файлов пакета, чтобы Git сохранял сырые логи и результаты побайтно.

## Быстрый вход

1. Прочитать `comparison.md`.
2. Загрузить `status-matrix.csv` для машинного сравнения.
3. Проверять спорное поле одновременно по четырём файлам `raw/*/codex-result.md`.
4. Для продолжения работы использовать `HERMES_HANDOFF.md`.
